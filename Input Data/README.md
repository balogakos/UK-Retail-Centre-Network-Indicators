# Input Data

This directory documents the two open-access spatial datasets required to reproduce the UK Retail Centre Street-Network Indicators from raw sources. Due to file size constraints (>1.5 GB for the UK OpenStreetMap PBF extract), raw input files are not tracked in Git.

## 1. CDRC Retail Centre Boundaries

- **File:** `retailcentre_bounds_uk.gpkg` (`N = 9,623` UK retail centre polygons in British National Grid, `EPSG:27700`)
- **Source:** Consumer Data Research Centre (CDRC) Retail Centre Boundaries data product
- **Access:** [https://data.cdrc.ac.uk/dataset/retail-centre-boundaries](https://data.cdrc.ac.uk/dataset/retail-centre-boundaries)

## 2. OpenStreetMap United Kingdom Extract

- **File:** `united-kingdom-latest.osm.pbf`
- **Source:** Geofabrik OpenStreetMap Data Extracts (United Kingdom)
- **Access:** [https://download.geofabrik.de/europe/united-kingdom.html](https://download.geofabrik.de/europe/united-kingdom.html)
