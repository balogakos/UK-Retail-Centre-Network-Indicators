# Input Data

This directory holds the spatial input datasets and provenance metadata required to run the indicator pipeline:

## 1. Geographic Data Service (GeoDS) Retail Centre Boundaries (Included)

- **File:** `Input Data/retailcentre_bounds_uk.gpkg` (`N = 9,623` UK retail centre polygons in British National Grid, `EPSG:27700`)
- **Source:** Geographic Data Service ([GeoDS](https://geods.ac.uk)) Retail Centre Boundaries data product
- **Access:** [https://data.geods.ac.uk/dataset/retail-centre-boundaries](https://data.geods.ac.uk/dataset/retail-centre-boundaries)

## 2. OpenStreetMap United Kingdom Extract (Download to `Input Data/`)

- **Raw PBF File:** `Input Data/united-kingdom-latest.osm.pbf`
- **Reference Extract Version Used in Published Outputs:** Geofabrik United Kingdom extract (`2,281,092,125` bytes, `2026-11-05T16:12:58Z`, fingerprint `d07046874ca657c9`)
- **Extracted 400 m Context Parquet (generated by `01_Extract_OSM_Networks.py`):** `Input Data/uk_roads_400m.parquet` (`2,646,803` highway segments in `EPSG:27700`)
- **Provenance Sidecar (generated by `01_Extract_OSM_Networks.py`):** `Input Data/uk_roads_400m.provenance.json`
- **Source:** Geofabrik OpenStreetMap Data Extracts (United Kingdom)
- **Access:** [https://download.geofabrik.de/europe/united-kingdom.html](https://download.geofabrik.de/europe/united-kingdom.html)
